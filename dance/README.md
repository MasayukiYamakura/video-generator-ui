# D-Generatorの使い方

専用画面: https://masayukiyamakura.github.io/video-generator-ui/dance/

## 初回だけ

1. GitHubでFine-grained personal access tokenを発行。対象を非公開の`chibi-dance-generator`に限定し、ActionsをRead and write、ContentsをRead and writeにする。Contentsの書込みは初回の参考動画登録に使う。
2. 専用画面の「接続・初回設定」にリポジトリ名とGitHubトークンを入力し「接続を確認」。Kaggle APIトークンは画面へ入力しない。
3. 保存は任意。保存しない場合はページを開き直したとき再入力する。保存したトークンは同じGitHub Pagesサイト内のコードから読めるため、共有端末では保存しない。
4. 「接続テスト（GPUなし）」を実行。これは色付きテスト動画と音を作る試験で、ダンス品質の試験ではない。
5. 「参考動画を登録する」で3方式から選択。DatasetはURLと動画パス、画面アップロードはMP4/MOVを指定。アップロードは以下の初期設定が必要。YouTube URLは現状では参考リンク保存で、ファイル登録が済むまで生成対象にはなりません。

## 日常の操作

参考ダンスを選び、開始秒・長さ1/2/5秒・音声を設定する。「動きを確認（CPU）」で骨格を確認し、「ダンスを生成（GPU）」へ進む。GPU生成は1秒から試す。実行内容の確認後に受付されれば、画面を閉じてもGitHub ActionsとKaggleで処理が続く。実生成の品質・所要時間・無料枠内での完了は未保証。

キャラは採用済みの大人頭身、黒フードで顔を隠しグレーデニム。承認済み原本の変更は行わない。画像は認証後だけ非公開リポジトリから読み込む。

## 状態確認と復旧

- 「状態を確認」は記録とGitHubの稼働状況を読み直す。Kaggleへの新規生成は行わない。
- 受付結果が不明な場合は「受付状況を確認」。必要な場合だけ「同じ依頼を再送」を使う。受付IDを固定し、サーバー側でも既存受付を照合する。
- 「結果だけ再取得」は記録済みのKaggle版を回収し直す。新しい生成を行わない。
- 未回収の依頼があると次の生成は保留する。Kaggle側で失敗したことと、GitHub側で回収・検査に失敗したことは別に表示する。
- GitHubの待機上限後もKaggleが動いている場合がある。GitHub側のキャンセルはKaggleの停止を意味しない。緊急停止はKaggle側で確認する。

## 結果の保存

動画は7日、詳細ログは30日の期限付きZIP。ダウンロード時はGitHubへのログインが必要。iPhoneではダウンロードしたZIPを「ファイル」で開き、展開したMP4を再生する。画面内動画再生・独自楽曲のアップロードと差し替え・長期保存・投稿は次段階。代表画像は認証後の画面で確認できる。

期限切れの動画は自動再生成しない。Kaggleに対象版の出力が残っていれば「結果だけ再取得」を試せるが、復元を保証するものではない。

## 開発と公開

この画面の編集元はダンス用非公開リポジトリの`tools/dance-ui/`。公開ファイルは許可リストから書き出し、`dance/`だけに反映する。V-Generator本体の原稿、占いタグ、公式LINE案内、投稿設定とは独立している。


## 接続できない場合

更新後にページを再読み込みしてから「接続を確認」を押してください。「GitHub APIへ通信できません」はブラウザとAPI間の通信失敗、「GitHub HTTP 401/403/404」は接続先や認証・権限の確認が必要な応答です。トークン自体をチャットやログへ貼り付けないでください。送信後の通信失敗では、先に「状態を確認」を使ってください。


## 画面からのアップロード：GitHub Secretsを設定

Cloudflareのアカウント・Worker・D1・URL設定は不要です。
非公開のchibi-dance-generatorリポジトリのActions Secretsへ、以下を登録します。

- DANCE_CLOUDINARY_CLOUD_NAME
- DANCE_CLOUDINARY_API_KEY
- DANCE_CLOUDINARY_API_SECRET

既存のKAGGLE_API_TOKENはそのまま使います。V-GeneratorのSecretsは自動でコピーされません。秘密情報を画面やチャットへ貼り付けないでください。

GitHubへ接続し、動画を選択して「素材を登録（GPUなし）」を押すと、Actionsが暗号化したアップロード許可を返します。Actionsの起動待ち中は画面を閉じても、同じブラウザから「登録を再開」で続けられます。動画転送中は画面を開いてください。転送中ずっとActionsを待機させる構成ではありません。

復号鍵はこのブラウザ内に保存します。転送前にブラウザのサイトデータを削除した場合は、新規登録が必要になることがあります。転送の応答が不明な場合は、再開時にCloudinaryの受領状況を先に確認します。

詳細：[素材登録・初期設定手順](https://github.com/MasayukiYamakura/chibi-dance-generator/blob/main/docs/reference-ingestion.md)。

YouTubeは参考リンク保存で、自動取得は引き続き無効です。GPU生成は素材登録完了後の別操作です。
