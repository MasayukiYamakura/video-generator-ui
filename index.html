PERSONAL VIDEO STUDIO

V-Generator

録音と台本から、投稿する一本へ。

GitHub接続設定

保存すると、このブラウザで利用する同じGitHub Pagesオリジンのコードから読み取れます。共有端末では保存しないでください。

設定・運用ガイド
設定の保存

音声・BGM・出力形式と縦型／横型のデザインを動画プリセットに保存します。原稿・カード・今回の手動フック文章・素材検索語は保存対象外です。保存だけでは動画を生成しません。

読込は未保存のデザイン変更を破棄し、保存済みの値に戻します。

生成後の自動連携

オン：縦型はCloudinaryへ自動転送し、投稿一覧へ登録。横型はYouTube投稿用の一覧へ登録します。オフ：生成とダウンロードのみ。必要な動画だけ履歴から手動連携できます。SNSへの投稿は別途確認が必要です。

ナレーション原稿

01 音声ファイル

ボイスメモを「ファイル」に保存して選択。m4a / mp3 / wav / aac / ogg / flac / mp4 / aiff / aif に対応。

制作の基本設定

設定を選び、AIへ渡すプロンプトを作ります。従来のJSONだけで生成する場合、この画面の設定は適用されません。

月間星座タロット専用設定

このエリアは月間星座タロットのプリセットを選んだ時だけ表示します。実際に引いた4枚のカードを選択してください。解釈はナレーション原稿に含めます。AIのJSONでカードは変更されません。

CTAを使う場合、上のナレーション原稿にはCTA文を重複して入れず、この欄へ最後の一文を入力してください。

ナレーション原稿は画面上部へ入力し、プロンプトを生成してください。カードは正位置・逆位置を選べます。動画は原稿の長さに合わせます。

複数星座の制作（1〜12星座）

12星座の入力と端末に保存された下書きを消します。接続情報と生成履歴は残ります。

年・月・期間・音声・BGMは全星座で共通です。各星座のカード4枚と原稿を入力し、12星座をまとめてAIへ渡し、回答を一度に取り込みます。欠けた星座があればその分だけ追加できます。読み上げ原稿にはCTAを含めません。制作対象のチェックを外すと、その星座だけ除いて再実行できます。

12星座の占い結果を一括入力

先に専用プロンプトをAIへ渡し、返された占い結果JSONを貼り付けます。この欄は下の動画用シーンJSONとは別です。反映すると12星座の既存のシーン回答は無効になります。エラー時は入力欄を変更しません。






音声・BGM
読み上げの詳細設定
匿名加工設定：ピッチ -1.5、フォルマント保持、EQ +1 / -0.5 / +0.5 dB。独自の値は詳細設定で画面設定の適用をOFFにし、JSONで指定できます。


縦型・横型のデザイン
編集する形式を選んで表示・素材・位置を設定します。プレビューも同じ形式に切り替わります。出力しない形式の設定も保持します。
タロット共通の表示・配置
ここは縦型・横型で共通です。Remotionのカード・本編字幕の配置は固定です。横型のテーマ・サブタイトル・アイコンは上の横型タブで設定します。


原稿・AI設定
シーン分割はAIに任せます。明示した値はAIの返答で変更されません。








プレビュー


実際のタイトル・改行を使った簡易プレビューです。背景動画・実カード・音声は再現しません。端末と生成環境のフォント差によって字幅は多少異なります。縦型はTikTokの操作表示とタイトル範囲、横型は外周5％の安全余白を表示します。ガイドは動画に入りません。sizeは波形キャンバス、バーの見える幅は表示幅比率で調整します。


プレビュー・ガイド設定
ガイドは完成動画に入りません。縦型のガイド比率はデザインの各形式に保存されます。



JSON・適用方法の詳細設定
AIの返答は下のscript.json欄へ貼り付けます。画面設定を適用する場合、シーンの表示・位置・音声・BGM等はプロンプト生成時の確定値で置き換えます。



プリセットは、保存ボタンを押すまで変更されません。




02 台本を設定
BGM設定なしの場合は、BGMを追加しません。
録音方式ではaudio_fileを選択した録音に紐付けます。AI読み上げでは録音の選択は不要です。Prompt Builderの「送信時に画面設定を適用」がOFFの場合、その他の設定は変更しません。画像などの素材は現行リポジトリのmediaを使います。




03 動画を生成
生成に使う設定
選択した本数分のAI読み上げと動画制作を順番に実行します。制作指示後は画面を閉じられます。成果物は星座ごとにダウンロードできます。
実行受付が完了するまで、この画面を開いてください。


生成履歴
受付後は画面を消しても生成が続きます。戻ると状況を更新します。自動連携をオンにすると生成後に投稿管理へ自動登録されます。一覧にない場合に取り込んでください。取り込みだけでは投稿されません。
GitHub接続後、共通履歴を読み込みます。過去の端末履歴は初回に移行します。

横型の完成動画をまず非公開でアップロードします。Studioで再生して内容を確認し、処理完了を照合した後で公開・限定公開・予約公開を設定できます。縦型のBuffer投稿は下の欄から利用できます。
初回認証・運用ガイド
生成履歴の実行IDから取り込む
横型の完成動画
一覧の取り下げは表示の整理だけです。動画ファイル・投稿記録・SNS上の動画は削除しません。
YouTubeの改変・合成コンテンツの説明
最初のアップロードは非公開です。公開・予約は送信結果の欄から、動画を再生・確認してから設定します。
YouTubeの送信結果
結果不明の場合は新規送信せず、同じ送信を照合します。送信情報が失われた場合や、予約後の変更・取消はYouTube Studioで確認してください。動画成果物の保存期限は3日です。
Bufferによる縦型投稿
完成動画を選び、3媒体へまとめて予約します。生成だけではSNSに投稿しません。
Secrets登録後、投稿先を取得してください。
接続情報は非公開リポジトリのSecretsに登録します：CLOUDINARY_CLOUD_NAME / CLOUDINARY_API_KEY / CLOUDINARY_API_SECRET / BUFFER_API_KEY。動画URLは公開の配信用URLになります。
Instagramの場所
未設定（場所なしで予約できます）
場所指定は任意です。Bufferで場所欄が表示されない場合もInstagramへの予約を続けられます。場所機能を使うには、InstagramをFacebookページ経由でBufferに接続する必要があります。対応する接続で「大阪市」を選んだ下書きがある場合だけ、下のボタンで場所を取得できます。取得後の新規予約・失敗投稿の再予約に適用します。TikTok・YouTubeの場所指定はBuffer経由では非対応です。

投稿内容・日時の一括設定
星座別の投稿情報がある動画は、個別説明文・公式LINE案内・タグ5個を使用します。以下の定型文は投稿情報のない過去動画向けです。
選択した一覧の順で時刻をずらします。同じ動画の各SNSは同時刻です。各投稿を開くと個別に変更できます。無料枠は各投稿先10件。枠待ち分は後で追加予約してください。
予約・公開状況
予約済み投稿の変更・取り消しはBufferで行います。公開失敗は「この投稿先だけ再予約」で日時を確認して再実行できます。結果不明の投稿は二重登録を防ぐため再送を保留します。すべての対象投稿の公開完了を確認して24時間後以降、Cloudinaryの動画を自動削除します。
