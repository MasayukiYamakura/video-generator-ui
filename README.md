# 動画生成スタジオ（iPhone対応）

公開UIは`MasayukiYamakura/video-generator-ui`のGitHub Pages、動画生成と設定・履歴の保存先は非公開の`MasayukiYamakura/video-generator`です。

## 日常の操作

1. 接続設定で非公開の生成リポジトリとGitHubトークンを指定し、接続します。
2. 「保存済み設定を読込」で自分のプリセットとBGM一覧を取得します。
3. TikTok標準／月間星座タロット／YouTube横型を選びます。
4. 原稿・カード・音声方式などを設定してプロンプトを生成します。外部AIへコピーするか、対応するGemini直接生成ボタンを使用します。
5. AIのJSONを取り込み、内容・プレビューを確認して生成します。録音・匿名加工では音声を添付します。
6. 実行受付が完了すれば画面を閉じられます。生成履歴から星座ごとのZIPを取得できます。動画本体の保存期間は3日です。

JSONの引用符はASCIIの半角ダブルクォートです。設定を変更した場合はプロンプトを生成し直してください。旧JSONをそのまま送るときは「送信時に画面設定を適用」をOFFにします。

## プリセットの選び方

- TikTok標準：「TikTokの見た目」で標準／従来の縦書きフックを選べます。従来の縦書きフックのテンプレート・背景・字幕配置も維持しています。匿名加工は音声方式から選びます。
- 月間星座タロット：Remotionで描画します。「制作する星座」が1星座なら録音・匿名加工・AI読み上げ、複数星座ならAI読み上げで1〜12星座を選択できます。月全体／前半／後半、カード正逆、CTAに対応します。
- YouTube横型：既存の横型動画を生成します。media内の背景ファイル名は初期状態から編集でき、入力すると背景素材を「固定画像のみ」へ切り替えます。外部映像を一部のシーンに入れる場合は、その後で背景素材を「背景画像＋一部動画」に変更し、素材シーンの割合または番号を設定してください。画像を使うシーンでは指定した横型画像を表示します。変更した設定を残す場合は別名で「新規保存」してください。

モードの切替前後で入力欄とページ内の設定を保持します。複数星座の下書きは同じ端末に保存します。単体入力を複数星座へ自動転記はしません。複数星座では、未取込分だけAIへ追加依頼し、制作対象のチェックで再生成する星座を絞れます。

保存済みの自作プリセットは引き続き選べます。「上書き保存」「新規保存」は背景ファイル名・音声・BGM・レイアウトを非公開の`config/prompt-builder.json`へ保存します。他端末との競合時は再読込してください。保存では動画生成を起動しません。旧プリセットを継承する設定は読み込み時に互換変換します。

## プレビュー

簡易プレビュー、中央ガイド、右側のTikTokボタン用ガイド、対象プリセットの左右10%のタイトル用ガイドを表示します。ガイドは動画には入りません。簡易プレビューは背景動画や実カード映像の完全な再現ではありません。文字サイズの計算は各描画方式に合わせます。

## 共通履歴と通信断

生成処理が共通履歴を保存し、画面は読み込みます。旧端末履歴は初回に一度だけ移行します。通常更新で端末履歴を再送しません。移行失敗時は元データを保持し、次回再試行します。移行後は進行中と直近50件を表示用に保存します。

未受付の依頼や受付IDは復旧のため端末に保持します。通信断では「受付状況を確認」を使い、必要な場合だけ同じ受付IDで再送します。履歴保存が終了時も失敗した場合はActionsが失敗になります。動画Artifactが作成済みならそのダウンロードは可能です。共通履歴に動画・音声・台本本文・認証情報は保存しません。

## SNS投稿

生成履歴の「投稿を準備する」からCloudinaryへの転送を依頼し、SNS投稿管理でTikTok／Instagramリール／YouTubeショートへ予約します。生成だけでは投稿されません。タイトルは動画ファイル名から拡張子を除いたものです。

初回Secretsは`CLOUDINARY_CLOUD_NAME`、`CLOUDINARY_API_KEY`、`CLOUDINARY_API_SECRET`、`BUFFER_API_KEY`です。Instagramの大阪市設定、カバー開始0秒、失敗投稿先だけの再予約などは非公開生成リポジトリの`docs/SNS_PUBLISHING.md`を参照してください。

## 開発・公開

この画面は非公開の生成リポジトリから、検証済みのファイルだけを自動反映します。
開発の正本は[生成側の文書索引](https://github.com/MasayukiYamakura/video-generator/blob/main/docs/INDEX.md)、手順は[開発手順](https://github.com/MasayukiYamakura/video-generator/blob/main/docs/DEVELOPMENT.md)と[公開手順](https://github.com/MasayukiYamakura/video-generator/blob/main/docs/DEPLOYMENT.md)です。
`source-version.json`には公開物の元コミットとハッシュが記録されています。認証情報や非公開設定は含みません。
公開リポジトリ内のファイルを直接修正する運用は行いません。

## 単体動画の投稿文

TikTok標準、縦書きフック、星座単体、YouTube横型の新しいプロンプトは、原稿に合わせた説明文と関連ハッシュタグをAIへ依頼します。一般動画は関連3個、星座動画は関連2個です。投稿確認欄に固定LINE案内、`#大阪 #占い`（星座動画は星座名も）を加えた合計5タグが入ります。予約前に内容を確認し、必要なら編集してください。以前に生成した動画は共通定型文を使います。

## 12星座の投稿文・途中再開

新しい占い結果用プロンプトは星座別の説明文と関連ハッシュタグ2個も生成します。
投稿確認時に`#大阪 #占い #星座名`と公式LINE案内が付き、合計5個のタグになります。旧動画は共通定型文を使えます。
TikTok・Instagramは本文冒頭に動画タイトル、YouTubeは専用タイトル欄を使用します。
一括TTSが中断したら履歴を更新し、「未完了分を再開」を押します。日次上限では表示された再開目安とAI Studioの上限を確認してください。
保存済み音声は7日間再利用できます。完成動画は3日間です。音声生成の結果不明では利用状況を確認してから再開してください。

## 複数星座の見た目を変える

制作対象のチェックボックスは各星座の見出し右側にあります。閉じたまま選択でき、チェック操作では内容は開閉しません。星座名を押すと内容が開閉します。

各星座を開くと「背景の色合い」「通常のシャッフル」「レボリューションカット」「円形スプレッド」「カード裏面」を選べます。
各動きのAは従来版です。1本の中で3種類すべての動きを使用します。
共通の5項目を選び「選択中の星座へ映像設定をまとめて適用」すると、制作対象の星座だけへ反映します。
「3種類の動きをプレビュー」で、背景・裏面と動きの違いを確認できます（簡易表示）。
新しい占い結果用プロンプトは、星座ごとに偏りを抑えたランダム設定をAIへ依頼します。
JSON取り込み後も手動変更でき、後続のシーン取り込みで設定は変わりません。
古いJSONも使用でき、映像設定が省略されていれば現在の選択を保持します。

## 縦型と横型を一緒に作る

TikTok標準・従来の縦書きフック・月間星座タロットで「出力形式」を選べます。初期値は縦型のみです。「縦型＋横型」は1つの原稿・音声から2本、「横型のみ」は同じデザイン系列の横型だけを作ります。既存のYouTube横型プリセットは別の見た目です。

縦横は同じ内容・尺で、横型は1920×1080です。プレビューを切り替えて配置を確認してください。複数星座は1星座につき最大2本です。

履歴で縦横の状態を確認できます。単体は形式別ZIP、複数星座は星座別ZIP内のvertical／landscapeフォルダから取得します。失敗した形式は、保存データが有効な間だけ再開できます。動画は3日、再開用音声・入力は7日です。

追加横型はSNS投稿管理へ転送されません。ダウンロードしてYouTube通常動画へ手動で投稿してください。縦型の既存投稿操作は変わりません。


## 縦型・横型のデザインを個別に保存

このエリアでは、縦型／横型を切り替えて表示・配置・背景・テーマ・アイコンなどを編集します。出力形式を変えても両方を保持します。
思想語りでは生成動画とプレビューに適用します。Remotionタロットは横型の右上テーマ・サブタイトル・アイコンに対応します。縦型・カード・字幕・アニメーションは従来の固定レイアウトです。テーマを空欄にすると、各星座の年月・期間・星座名を使います。アイコンは既定でOFFです。ONにする場合は指定画像を非公開リポジトリのmedia内へ用意してください。外部映像中の表示はテーマ・サブタイトル・アイコンごとに選択できます。未設定項目は「今回の設定」「レイアウト調整・保存」を引き継ぎます。変更後はプロンプトを生成し直してください。
保存は「レイアウト調整・保存」の新規／上書き保存ボタンを使用します。設定読込後に保存したプリセットを選べば、別端末でも復元できます。未保存の編集はページを閉じると失われます。
「保存済み設定を読込」を押すと、未保存の形式別編集を捨てて保存済み値へ戻ります。入力エラーがある場合は修正してから形式・プリセットを切り替え、保存してください。

思想語りは従来のTikTok標準を改称したものです。縦横の原稿・音声・シーン・BGMは共通で、横型だけ別原稿を作る必要はありません。保存済みYouTube横型の設定は思想語りの横型へ引き継ぎ、元の互換プリセットも残します。
プレビュー形式と編集タブは連動します。背景は「背景画像を読込・プレビュー」で読み込みます。「外部映像中の表示を確認」は配置・表示の確認用です。人物・アイコンの別素材は枠で示し、実際の映像は生成後に確認してください。

一括制作は選択した星座を順番に処理し、各星座が終わるごとに音声と成功した動画を保存します。一部が失敗した場合は履歴から未完了分を再開してください。保存期間と操作方法は従来どおりです。

## 月間MBTIタロット

「月間MBTIタロット」を選び、単体／複数タイプを切り替えます。年月と月全体・前半・後半、4枚のカード、読み上げ原稿を設定します。16タイプの占い結果をAIで作成し、シーンJSONを取り込む手順は星座と共通です。制作対象は各タイプのチェックで選びます。
単体は録音・匿名加工・AI読み上げ、複数タイプはAI読み上げです。縦型のみ・縦横同時・横型のみを選べます。横型のテーマ・サブタイトル・アイコンも保存できます。
星座とMBTIの下書きは別です。途中で止まった場合は生成履歴から未完了分を再開します。保存音声は7日、動画は3日です。AI無料枠の上限は従来と同じで、解除や全16件の完了を保証するものではありません。新たなAPIキーや課金設定は不要です。

## YouTube通常動画（横型・非公開テスト）

SNS投稿管理の先頭に横型専用の欄があります。縦型のBuffer投稿は従来の欄を使います。横型は非公開固定で、公開・予約は次の段階です。初回認証の前でも動画生成・Buffer投稿は利用できます。

### 初回だけ本人が行うこと

1. Google Cloud Consoleで利用するプロジェクトを選び、YouTube Data API v3を有効にします。請求先の登録・有料契約はこの機能では不要です。課金有効化を求められた場合はそこで止めてください。
2. Google Auth Platformの同意画面を設定し、本人のGoogleアカウントをテストユーザーへ登録します。OAuthクライアントは「デスクトップ アプリ」を作り、JSONをPCのGit管理外の場所へダウンロードします。
3. ブラウザを使える自分のPCにPython、GitHub CLIを用意し、非公開生成リポジトリへのSecrets書込みができるアカウントで`gh auth login`します。非公開生成側の最新版コードから以下を実行します。Codespaces上のloopbackやiPhoneのブラウザを初回認証の代わりに使わないでください。

```sh
python -m pip install requests==2.32.5
python scripts/youtube_oauth.py --client /path/to/downloaded-desktop-client.json
```

4. 開いたGoogle画面で本人が投稿先チャンネルを選び、アップロードと読取りに同意します。ターミナルのチャンネル名・IDを確認し`yes`を入力すると、4つのYouTube用Secretsを非公開生成側へ直接登録します。値をチャット・フォームへ貼る必要はありません。JSONはリポジトリに追加しないでください。
5. 投稿画面の「YouTubeの接続・投稿先を確認」を押し、チャンネル名・ID・カテゴリが表示されることを確認します。認証先と登録先が違う場合は送信しません。

外部OAuthがTestingの場合、更新トークンは通常7日で失効します。失効時は同じプロジェクトで再認証します。継続利用の公開ステータスやGoogleの確認事項は本人が管理してください。別プロジェクトへの自動切替・自動課金・自動増枠はありません。

### 日常の操作

PR7導入後に横型または縦横両方を生成すると、完成した横型が専用一覧へ登録されます。過去の生成実行は生成履歴の「横型をYouTube投稿へ」でも取込できますが、PR7より前の専用情報がない動画は対象外です。

動画と投稿先を確認し、タイトル、説明文、カテゴリ、子ども向け／現実と誤認される改変・合成コンテンツの有無を選択します。「内容を確認」後に「確認した内容で非公開送信・再開」を押します。1回1動画です。受付後は画面を閉じられます。YouTube Studioで実動画を再生し、音声・字幕・公開設定を確認してください。

通信中断時は「同じ送信の状態確認・再開」を使用します。別のアップロードを作りません。送信情報がない・セッション期限切れ・元動画が取得できない場合は新規送信を保留し、Studioで本人が確認します。動画IDを取得済みの動画は再送しません。生成成果物は3日間なので期限内に送信・再開してください。

コード公開の確認では本人のチャンネルへ動画を投稿していません。初回設定と実アカウントでの非公開テストは本人の作業として残ります。
