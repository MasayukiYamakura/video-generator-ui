PERSONAL VIDEO STUDIO

動画生成スタジオ

録音と台本から、投稿する一本へ。

GitHub接続設定

保存すると、このブラウザで利用する同じGitHub Pagesオリジンのコードから読み取れます。共有端末では保存しないでください。

設定・運用ガイド

ナレーション原稿

01 音声ファイル

ボイスメモを「ファイル」に保存して選択。m4a / mp3 / wav / aac / ogg / flac / mp4 / aiff / aif に対応。

Prompt Builder

設定を選び、AIへ渡すプロンプトを作ります。従来のJSONだけで生成する場合、この画面の設定は適用されません。

月間星座タロット専用設定

このエリアは月間星座タロットのプリセットを選んだ時だけ表示します。実際に引いたカードと解釈を入力してください。AIのJSONで結果は変更されません。

ナレーション原稿は画面上部へ入力し、プロンプトを生成してください。カードは正位置のみです。動画は原稿の長さに合わせます。

今回の設定
詳細設定

匿名加工設定：ピッチ -1.5、フォルマント保持、EQ +1 / -0.5 / +0.5 dB。既存DSP設定を適用します。独自の値はJSONのvoice_processingで指定し、画面設定の適用をOFFにしてください。

AI設定

シーン分割はAIに任せます。明示した値はAIの返答で変更されません。

レイアウト調整・保存

左上を原点とする動画のピクセル座標。入力値をそのままJSONへ反映します。縦書きフックは中心Yではなく上端Yを使用します。タグはportrait_brandで表示します。

実際のタイトル・改行を使った簡易プレビューです。フォント差があるため、実動画との表示差があります。水色の縦線・横線は画面の中央です。ガイド線と赤い領域は動画に入りません。sizeは波形キャンバス、バーの見える幅は表示幅比率で調整します。

非公開リポジトリへ設定だけを保存します。上書き保存は選択中のプリセットを更新します。新規保存では保存ID・表示名を入力してください。

プリセットは、保存ボタンを押すまで変更されません。

AIの返答は下のscript.json欄へ貼り付けます。画面設定を適用する場合、シーンの表示・位置・音声・BGM等はプロンプト生成時の確定値で置き換えます。

02 台本を設定

BGM設定なしの場合は、BGMを追加しません。

録音方式ではaudio_fileを選択した録音に紐付けます。AI読み上げでは録音の選択は不要です。Prompt Builderの「送信時に画面設定を適用」がOFFの場合、その他の設定は変更しません。画像などの素材は現行リポジトリのmediaを使います。

03 動画を生成

実行受付が完了するまで、この画面を開いてください。

生成履歴

受付後は画面を消しても生成が続きます。戻ると状況を更新します。
