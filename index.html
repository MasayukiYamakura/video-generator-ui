PERSONAL VIDEO STUDIO

動画生成スタジオ

録音と台本から、投稿する一本へ。

GitHub接続設定

保存すると、このブラウザで利用する同じGitHub Pagesオリジンのコードから読み取れます。共有端末では保存しないでください。

設定・運用ガイド

ナレーション原稿

01 音声ファイル

ボイスメモを「ファイル」に保存して選択。m4a / mp3 / wav / aac / ogg / flac / mp4 / aiff / aif に対応。

Prompt Builder

設定を選び、AIへ渡すプロンプトを作ります。従来のJSONだけで生成する場合、この画面の設定は適用されません。

月間星座タロット専用設定

このエリアは月間星座タロットのプリセットを選んだ時だけ表示します。実際に引いた4枚のカードを選択してください。解釈はナレーション原稿に含めます。AIのJSONでカードは変更されません。

CTAを使う場合、上のナレーション原稿にはCTA文を重複して入れず、この欄へ最後の一文を入力してください。

ナレーション原稿は画面上部へ入力し、プロンプトを生成してください。カードは正位置・逆位置を選べます。動画は原稿の長さに合わせます。

複数星座の制作（1〜12星座）

12星座の入力と端末に保存された下書きを消します。接続情報と生成履歴は残ります。

年・月・期間・音声・BGMは全星座で共通です。各星座のカード4枚と原稿を入力し、12星座をまとめてAIへ渡し、回答を一度に取り込みます。欠けた星座があればその分だけ追加できます。読み上げ原稿にはCTAを含めません。制作対象のチェックを外すと、その星座だけ除いて再実行できます。

12星座の占い結果を一括入力

先に専用プロンプトをAIへ渡し、返された占い結果JSONを貼り付けます。この欄は下の動画用シーンJSONとは別です。反映すると12星座の既存のシーン回答は無効になります。エラー時は入力欄を変更しません。




今回の設定
詳細設定
匿名加工設定：ピッチ -1.5、フォルマント保持、EQ +1 / -0.5 / +0.5 dB。既存DSP設定を適用します。独自の値はJSONのvoice_processingで指定し、画面設定の適用をOFFにしてください。


AI設定
シーン分割はAIに任せます。明示した値はAIの返答で変更されません。








レイアウト調整・保存
左上を原点とする動画のピクセル座標。入力値をそのままJSONへ反映します。縦書きフックは中心Yではなく上端Yを使用します。タグはportrait_brandで表示します。




実際のタイトル・改行を使った簡易プレビューです。Remotion版の冒頭は完成動画と同じ文字サイズ・行間・位置で表示します。端末と生成環境のフォント差によって字幅は多少異なります。黄色の縦線はタイトル用の左右10％ガイド、赤い領域と線はTikTokの操作表示用ガイド、水色の線は画面の中央です。ガイドは動画に入りません。sizeは波形キャンバス、バーの見える幅は表示幅比率で調整します。


非公開リポジトリへ設定だけを保存します。上書き保存は選択中のプリセットを更新します。新規保存では保存ID・表示名を入力してください。



プリセットは、保存ボタンを押すまで変更されません。


AIの返答は下のscript.json欄へ貼り付けます。画面設定を適用する場合、シーンの表示・位置・音声・BGM等はプロンプト生成時の確定値で置き換えます。


02 台本を設定
BGM設定なしの場合は、BGMを追加しません。
録音方式ではaudio_fileを選択した録音に紐付けます。AI読み上げでは録音の選択は不要です。Prompt Builderの「送信時に画面設定を適用」がOFFの場合、その他の設定は変更しません。画像などの素材は現行リポジトリのmediaを使います。




03 動画を生成
選択した本数分のAI読み上げと動画制作を順番に実行します。制作指示後は画面を閉じられます。成果物は星座ごとにダウンロードできます。
実行受付が完了するまで、この画面を開いてください。


生成履歴
受付後は画面を消しても生成が続きます。戻ると状況を更新します。
GitHub接続後、共通履歴を読み込みます。過去の端末履歴は初回に移行します。
SNS投稿管理
完成動画を選び、3媒体へまとめて予約します。生成だけではSNSに投稿しません。
Secrets登録後、投稿先を取得してください。
接続情報は非公開リポジトリのSecretsに登録します：CLOUDINARY_CLOUD_NAME / CLOUDINARY_API_KEY / CLOUDINARY_API_SECRET / BUFFER_API_KEY。動画URLは公開の配信用URLになります。
Instagramの場所
大阪市（初回取得が必要）
初回のみ、BufferでInstagramの下書きに「大阪市」を選択して保存し、下の取得ボタンを押してください。投稿・予約は不要です。Facebookページ経由のInstagram接続が必要です。取得後は新規予約・失敗投稿の再予約に自動適用します。TikTok・YouTubeの場所指定はBuffer経由では非対応です。
カバーはInstagram・TikTokで開始0秒を指定します。YouTubeはBuffer経由では指定できません。最初のフレームに表示されている画面が使われます。
投稿先
生成済み動画
投稿内容・日時の一括設定
選択した一覧の順で時刻をずらします。同じ動画の各SNSは同時刻です。各投稿を開くと個別に変更できます。無料枠は各投稿先10件。枠待ち分は後で追加予約してください。
予約・公開状況
予約済み投稿の変更・取り消しはBufferで行います。公開失敗は「この投稿先だけ再予約」で日時を確認して再実行できます。結果不明の投稿は二重登録を防ぐため再送を保留します。すべての対象投稿の公開完了を確認して24時間後以降、Cloudinaryの動画を自動削除します。
